# Embedded Book 2 Dummy Boot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove B01 and B02 using real early-boot device access controls and dummy endpoints inside one disposable x86-64 guest.

**Architecture:** A diskless TCG guest boots a pinned Linux kernel and a static fixture as PID 1. The fixture installs and tests a deny policy before inventory, then delegates only one immutable dummy device to a supervised worker. A host verifier checks the current boot's ordered receipts and negative controls, not just the emulator exit status.

**Tech Stack:** Linux stable v7.3.5 `988117cc1bb17338c586a4e21ade88b5397eac33`, GCC C17 with static libc, Linux UAPI `bpf` and `seccomp`, QEMU x86-64 11.1.3 with TCG, Python 3.

**Spec:** [Supervised capture lab design](../specs/2026-11-28-embedded-book2-lab-boundary-design.md) and [ADR-0042](../../architecture/adr/0042-embedded-book2-rgb-ir-class.md). This first plan covers B01/B02 only. Gate B03 needs the reviewed limited discovery and IPA contract; B04 through B11 need the observer/producer and disposition plan after the boot proof. B12 is outside this plan.

## Global Constraints

- No physical device passthrough, installed boot change, host cgroup/BPF/kernel mutation, live Book 2, real camera node, strobe, PAM, daemon, model, account, TPM or keyring. No host `sudo`, system-wide installation or access to another worktree.
- Only the disposable QEMU guest uses PID 1, root and kernel policy. Do not use a VM with an existing disk, production image, sockets, network access, USB devices or host shares. Make the host runner's option vector fixed and deny all caller-supplied extra QEMU flags.
- Use private `/tmp/opencode` build trees and an initramfs with only this test binary and the listed dummy nodes. Do not bridge, persist or export guest device descriptors. No system `libbpf` dependency or new Cargo package. No production workspace, package, CI, schema or path changes.
- At execution, recheck the exact public Linux and QEMU versions and record the hash of source, config, build tools, kernel image, initramfs and receipts. The current Archhost plan preflight found QEMU 11.1.3, GCC and readable static libc; no guest was booted and no kernel was built.
- Both B01/B02 are real checks of this dummy guest only. No observation about the actual Book 2, media-graph lifetime, libcamera discovery, teardown, optical OFF or authentication follows. Unclear, skipped or failed required checks are refusal, not a partial pass.
- Use a separately authorized execution scope and the existing isolated worktree. Keep commits local, signed and DCO-signed-off. No issue, PR, publication or reporter contact.

## Review Focus

- `test_zero_exit_without_receipt_fails`: QEMU zero without the current nonce and exact event sequence does not pass (Task 1).
- `early_deny_missing`: a launch reaching an open before verified default denial must not produce inventory or worker receipts (Task 2).
- `alias_and_access_set`: the same encoded char device must deny a peer via both names; a worker with read permission must not acquire write or mknod authority (Task 2).
- `non_replacement`: failure to rename an alias is not proof of a stable device. Validate the fixed compiled registration and reject an attempted module-based replacement under the actual guest kernel (Task 2).
- `retained_fd_and_transfer`: real descriptor inheritance, proc access and FD-bearing IPC must be tested independently of the device cgroup; a failed sanitizer must halt the worker stage (Task 3).

### Task 1: Build and verify the diskless guest harness

**Files:** `kernel.config`, `build_guest.sh`, `run_guest.py`, `test_run_guest.py`, `guest/init.c`, `guest/lab.h`, `README.md`.

**Interfaces:** `bash "$LAB/build_guest.sh" "$LINUX" "$SCRATCH/build"` stages `bzImage`, `initramfs.cpio` and `build.sha256` under the private output directory. `python3 -B "$LAB/run_guest.py" "$SCRATCH/build" "$SCRATCH/receipt" smoke` performs one bounded run. `check_receipt(text: str, nonce: str, case: str, returncode: int) -> tuple[str, ...]` refuses invalid results. Every event is printed by trusted PID 1 as `BOOK2_BOOT_V1 <nonce> <event>`, one line per event. `lab_event(const char *event)` in `guest/init.c` owns that output.

- [ ] **Write verifier tests.** `test_zero_exit_without_receipt_fails`, `test_wrong_nonce_or_order_fails`, `test_success_prefix_followed_by_error_fails`, `test_unsafe_launch_options_are_absent`. For `smoke`, only `("PID1", "SMOKE_ONLY")` with emulator exit 0 passes. Test corrupted artifact digest and swapped kernel/initramfs bindings. Example assertion: `assert check_receipt(smoke, nonce, "smoke", 0) == ("PID1", "SMOKE_ONLY")`.
- [ ] **Run RED.** `python3 -B -m unittest discover -s "$LAB" -p test_run_guest.py` must reject the temporary verifier that accepts a zero exit or broad launch options.
- [ ] **Implement verified build inputs.** Verify `git rev-parse HEAD` and a clean source checkout. Run `make -C "$LINUX" O="$SCRATCH/kbuild" ARCH=x86 x86_64_defconfig`, then `bash "$LINUX/scripts/kconfig/merge_config.sh" -m -O "$SCRATCH/kbuild" "$SCRATCH/kbuild/.config" "$LAB/kernel.config"` and `make -C "$LINUX" O="$SCRATCH/kbuild" ARCH=x86 olddefconfig`. Verify effective options before building `bzImage` and `headers_install`. Require `BLK_DEV_INITRD`, `BINFMT_ELF`, `PROC_FS`, `SYSFS`, `TMPFS`, `CGROUPS`, `BPF_SYSCALL`, `CGROUP_BPF`, `SERIAL_8250_CONSOLE`, `ACPI`, `UNIX`, `SECCOMP_FILTER` built in. Require `MODULES`, `MEDIA_SUPPORT`, `DEVMEM`, `DEVPORT`, `IO_URING`, and `X86_X32_ABI` off. Fail if a required config is absent rather than borrowing host kernel features. Compile the fixture static with GCC C17, `-D_GNU_SOURCE -Wall -Wextra -Werror`, the exported pinned UAPI, and `readelf` evidence of no dynamic dependency.
- [ ] **Stage exact initramfs and bounded launch.** `gen_init_cpio` comes from the pinned Linux source. The manifest defines directories `/dev`, `/proc`, `/sys`, `/run`, `/tmp`; static `/init`; `/dev/console` char `5:1`; `/dev/zero`, `/dev/book2-alias` char `1:5`; and `/dev/null` char `1:3`. Create nodes in archive metadata, not on host. QEMU uses `-machine q35,accel=tcg -m 512 -smp 1 -nodefaults -display none -monitor none -nic none -no-reboot`, exact verified `-kernel/-initrd`, `-serial file:<fresh-private-file>`, and `-append 'console=ttyS0 rdinit=/init panic=-1 book2_case=... book2_nonce=...'`. Use only canonical scratch paths without commas or line breaks. Set a finite 60-second wall timeout per boot, end the scoped emulator on failure and retain partial serial results without converting timeout to success. Refuse a kernel panic or Oops even after an apparent success receipt. PID 1 validates fixed-case syntax and the nonce; powers off without a rescue shell after the expected smoke event. No writable disk.

### Task 2: Enforce deny before inventory and prove the dummy device scope

**Files:** `guest/{lab.h,init.c,device_policy.c}`, `run_guest.py`, `test_run_guest.py`, `README.md`.

**Interfaces:** `int attach_device_filter(int cgroup_fd, bool permit_zero_read)` loads and attaches a `BPF_PROG_TYPE_CGROUP_DEVICE` program with `BPF_CGROUP_DEVICE` through the guest `bpf` syscall. `int enter_group(const char *group, pid_t pid)` writes the known group `cgroup.procs`, then verifies `/proc/<pid>/cgroup`. `int probe_zero_nonreplacement(void)` returns success only for the exact fixed dummy contract. Cases `policy` and `missing-deny`. Expected positive sequence: `PID1, DENY_ATTACHED, PRE_INVENTORY_DENIED, DUMMY_IDENTIFIED, WORKER_POLICY_ATTACHED, ALIAS_ACCESS_CHECKED, REPLACEMENT_REFUSED, POLICY_PASS`. Expected missing-deny control: `PID1, REFUSED_NO_INITIAL_POLICY` and no inventory/worker events.

- [ ] **Write real policy checks and RED.** With the deny stub, `open("/dev/zero", O_RDONLY)` would succeed; the positive `policy` test must fail, and the `missing-deny` control must stop before `DUMMY_IDENTIFIED`. Require `fd == -1 && errno == EPERM` in quarantine while both equal-mode alias nodes exist. `alias_and_access_set` must test both aliases in deny and authorized groups, read versus write/mknod, and `/dev/null` as the different minor. For the cgroup mknod control use a confined trusted guest probe with mknod capability and a writable private directory, so a permission failure is not inferred from the later worker's dropped capability. `non_replacement` checks compiled `MODULES=n`, built-in `1:5` sysfs identity and fixed ownership; a dummy replacement attempt must not succeed. Never treat alias creation itself as replacement of the kernel endpoint.
- [ ] **Implement the bootstrap policy.** Mount fresh proc/sysfs/cgroup v2 inside the guest. Before inventory or any general process, attach an all-denied device program to the quarantine cgroup and enter/verify it for trusted PID 1. Unknown char/block numbers are denied without inventory. Prove with denied opens of the existing dummy paths, not missing file paths. PID 1 only retains the trusted boot console and verified control descriptors. Install a sibling authorized group whose filter admits exactly char major `1`, minor `5`, read access alone, using the pinned `(access << 16) | dev_type` encoding. Do not allow path aliases to affect the decision. The inherited root scope cannot unconditionally deny an authorized descendant; verify actual effective access in both sibling groups. To keep the proof local to the guest, the PID 1 policy probes may briefly enter the authorized scope and must return to quarantine before any worker launch.
- [ ] **Prove non-replacement, not race detection.** Select the fixed built-in memory-device registration for this guest only. Before granting access, correlate `/sys/dev/char/1:5`, observed `stat` type/device and the fixed source registration; require the exact identity throughout this boot. The verified guest config excludes loadable modules, and the recognized `mem` class registration has no replace/unbind path in this boot. Demonstrate `delete_module` for the dummy cannot succeed (require the pinned disabled-module syscall result in the trusted, pre-seccomp probe), and deny an unauthorized `mknod`/rebind attempt under the actual policy. Log the two distinct conclusions: alias access follows `dev_t`; the selected kernel object cannot be replaced in the stated controlled boot. If the source/config or observed node contradicts either, refuse; do not invent a TOCTOU guarantee for real media.
- [ ] **Run GREEN and commit.** Boot `missing-deny` and `policy` with separate nonces; require the declared event sequences, no acceptance through missing policy, actual allowed read returns zeros, matching aliases in both groups, `EPERM` in the deny cases, and refusal of the replacement probe. `assert "DUMMY_IDENTIFIED" not in check_receipt(missing, nonce, "missing-deny", 0)`. Retain per-probe status and exact `dev_t`. Commit `test(research): verify early device policy in dummy boot`.

### Task 3: Prove workers cannot inherit or import dummy-device authority

**Files:** `guest/{lab.h,init.c,worker.c}`, `run_guest.py`, `test_run_guest.py`, `README.md`.

**Interfaces:** `int verify_worker_boundary(const char *quarantine, const char *allowed)` orchestrates trusted worker launch checks and returns 0 only after all probes pass. `int sanitize_worker(int first_untrusted_fd, uid_t uid, gid_t gid)` closes all extra descriptors using `close_range`, clears supplementary groups, sets real/effective/saved guest UID/GID, sets no-new-privileges and applies a reviewed x86-64 syscall filter for this fixture. Use guest UID/GID `65532` for the owner and `65533` for the peer. Full case `boundary`, negative case `kept-fd`. Both use the verified `policy` event sequence as a prefix, including `POLICY_PASS`. Append `INHERITED_HANDLE_CLOSED, PEER_HANDLE_DENIED, FD_IPC_DENIED, BOOT_BOUNDARY_PASS` for `boundary`; append only `REFUSED_RETAINED_HANDLE` for `kept-fd`.

- [ ] **Write refusal tests and RED.** Set up a real held read-only dummy descriptor inside a controlled positive branch and pass a seeded copy numbered above stdio to the launch sanitizer. Without the sanitizer, `fcntl(fd, F_GETFD)` succeeds; fail `retained_fd_and_transfer` until it instead returns `EBADF`. Probe `/proc/<worker>/fd/<held>` from a different dropped UID while the known owner and descriptor still exist; require permission denial, not `ENOENT`/process exit. Check denied descriptor-bearing `sendmsg`/`recvmsg` return `EPERM` and no higher descriptor is present. For `kept-fd`, require a deliberate retained dummy handle to produce `REFUSED_RETAINED_HANDLE` before any would-be discovery event.
- [ ] **Implement controlled process boundaries.** Fork with only audited launcher code, using a reserved pipe and explicit handshake before giving a worker the allowed group. Verify the group before releasing the child, and do not start any test worker before B01. Only safe stdio/control pipes can survive descriptor close. Use distinct unprivileged guest UIDs for owner and peer, no new privileges, and a small architecture-checked seccomp filter to block creation/use of FD-bearing sockets/messages and cross-process descriptor acquisition. Verify actual launcher/drop status and multiple denied actions; no claim this fixture policy suffices for libcamera/IPA. Monitor and wait for all known workers rather than treating cgroup emptiness as revocation. The kept-fd control uses an explicit test-only stub in the isolated guest, not an installed option.
- [ ] **Run GREEN and commit.** Boot all cases anew, verify `boundary` and negative receipts, keep child timeouts bounded and fail if no assertions ran. Run the whole host fixture test suite and isolated real guest controls twice from new receipt directories; measure no hardware. Commit `test(research): verify dummy worker descriptor boundaries`.
